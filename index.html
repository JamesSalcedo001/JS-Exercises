What comes after these projects?
  1. Foundation: HTML meaning, CSS layout, functions, state, forms, accessibility, Git, and reading errors in DevTools.
  2. Intermediate: modules, asynchronous requests, server validation, SQL, transactions, automated tests, and client/server responsibilities.
  3. Later: authentication and permissions, database migrations, performance, logging, caching, deployment, and reviewing code with other developers.

Keep improving a working project. Add one responsibility at a time; these projects begin the path rather than cover every engineering skill.

How to build independence
  1. Write your plan before touching the editor.
  2. Try your own approach; reveal one hint when stuck.
  3. Test edge cases, then explain why it works.
  4. Retry from blank before you move on.
Knowing the concept is the starting point. Repeatedly writing and debugging it is the practice.
